## 5. No prompts between stages

- **Depends on:** 1
- **Contract:** the Script Readiness Analyst writes no suggested prompts
  in `session-plan.md` or `next-session-handoff.md`, and the Decision
  Facilitator no copyable prompt for the next session. Each ends with a
  plain line instead: the next agent, the task or section, and the files
  it reads. A stage is handed over only when the creator says so, and can
  be sent back for rework.
- **Tests:** no prompt text left in either agent; adapters regenerated
